CSS Basics 🎨

Während HTML das Gerüst baut, sorgt CSS für das Aussehen. Hier lernst du, wie du Farben, Schriften und Abstände einstellst.

Wie funktioniert CSS?

01. Der Aufbau von CSS

CSS besteht aus einem Selektor (welches Element soll verändert werden?) und den Eigenschaften in geschweiften Klammern.

  • h1 { color: blue; }
  • Erklärung: Alle Hauptüberschriften (h1) erhalten die Textfarbe Blau.

02. Farben & Hintergründe

Du kannst Farben über englische Namen, Hex-Codes (z. B. #000000) oder RGB-Werte definieren.

  • background-color: #fafafa; – Ändert die Hintergrundfarbe.
  • color: #333333; – Ändert die Textfarbe.

03. Schriften & Text-Styling

Bestimme, wie deine Schriftarten aussehen und wie groß sie sein sollen.

  • font-family: Arial, sans-serif; – Legt die Schriftart fest.
  • font-size: 1.5rem; – Ändert die Schriftgröße.
  • text-align: center; – Zentriert den Text.

04. Abstände & Rahmen (Box-Model)

Mit Abständen und Rahmen bringst du Struktur und Luft in deine Inhalte.

  • padding: 20px; – Innenabstand (Platz innerhalb eines Elements).
  • margin: 40px; – Außenabstand (Platz um das Element herum).
  • border: 1px solid #eaeaea; – Erstellt einen feinen Rahmen.
