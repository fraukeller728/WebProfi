Meine erste Website. 🚀

Willkommen zum Projekt! In den nächsten Schritten erstellst du deine eigene Webseite mit HTML und CSS und veröffentlichst sie kostenlos im Internet.

Schritt-für-Schritt Anleitung

01. GitHub-Account erstellen

GitHub ist die Plattform, auf der Entwickler_innen ihren Code speichern und Webseiten veröffentlichen.

  • Gehe auf github.com und klicke auf Sign up.
  • Nutze deine (Schul-)E-Mail-Adresse und wähle ein sicheres Passwort.
  • Bestätige den Verifizierungscode in deinem E-Mail-Postfach.

02. Neues Repository (Projekt) anlegen

Ein Repository ist dein Online-Projektordner für die Webseite.

  • Klicke oben rechts auf das Plus-Zeichen (+) → New repository.
  • Vergib einen Namen (z. B. meine-erste-website).
  • Wichtig: Wähle Public (Öffentlich), damit die Seite erreichbar ist.
  • Setze den Haken bei Add a README file.
  • Klicke unten auf Create repository.

03. Dateien erstellen (HTML & CSS)

Jetzt bauen wir die Struktur und das Design deiner Website.

  • Klicke auf Add file → Create new file.
  • Nenne die Datei exakt index.html (deine Startseite) und füge deinen HTML-Code ein.
  • Speichere mit Commit changes....
  • Erstelle eine zweite Datei namens style.css für dein Design.

04. Webseite kostenlos online stellen

Mit GitHub Pages wird dein Code zu einer echten Live-Website!

  • Klicke oben in deinem Repository auf Settings.
  • Wähle in der linken Menüleiste Pages.
  • Stelle unter Build and deployment > Branch von None auf main um.
  • Klicke auf Save. Nach ca. 2 Minuten ist deine Seite unter deinem Link erreichbar!

Nützliche Bausteine (HTML & CSS Cheat Sheet)

Wichtige HTML-Tags zum Ausprobieren:

  • <h1>Überschrift</h1> – Hauptüberschrift
  • <p>Mein Text...</p> – Textabsatz
  • <a href="https://...">Link-Text</a> – Hyperlink
  • <img src="bild.jpg" alt="Beschreibung"> – Bild einfügen

Hilfe-Bereich: Kopiervorlage für deine `index.html`

Dein Start-Code für die Hauptseite

Wenn du ganz neu startest, kannst du diesen Code kopieren, in deine index.html einfügen und anpassen:

<!DOCTYPE html>
<html lang="de">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Meine Startseite – Mein Projekt</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>

    <!-- Automatisches Menü -->
    <header id="header-placeholder"></header>

    <main>
        <section class="hero">
            <h1>Willkommen auf meiner Website! 🚀</h1>
            <p class="subtitle">Hier stelle ich mein Projekt vor.</p>
        </section>

        <h2>Über das Projekt</h2>
        <div class="card-grid">
            <div class="step">
                <h3>Mein Thema</h3>
                <p>Hier kannst du deinen ersten Text schreiben...</p>
            </div>
        </div>
    </main>

    <!-- Skript zum Laden der nav.html -->
    <script>
        fetch('nav.html')
            .then(response => response.text())
            .then(data => {
                document.getElementById('header-placeholder').innerHTML = data;
            });
    </script>
</body>
</html>
