Das Navigationsmenü 🧭

Wie baut man ein professionelles Menü und wie sorgt man dafür, dass man es nicht auf jeder Unterseite einzeln kopieren muss?

Der Trick: Einmal ändern, überall aktuell

01. Die Menü-Datei (nav.html)

Anstatt den HTML-Code für das Menü in jede einzelne Seite zu schreiben, erstellen wir eine eigene Datei namens nav.html.

  • Diese Datei enthält nur den reinen HTML-Code für dein Logo und deine Links (<nav>...</nav>).
  • Fügst du hier einen neuen Menüpunkt hinzu, taucht er automatisch überall auf!

02. Der Platzhalter im HTML

Auf all deinen anderen Seiten (wie index.html oder kontakt.html) brauchst du im Kopfbereich nur diesen einen Platzhalter:

  • <header id="header-placeholder"></header>
  • Das ist wie ein leerer Koffer, in den das Menü gleich hineingeladen wird.

03. Das Laden per JavaScript (Fetch)

Damit sich der Platzhalter füllt, nutzen wir einen kleinen JavaScript-Befehl am Ende der Seite:

  • fetch('nav.html') holt sich den Inhalt aus deiner Menü-Datei.
  • .then(data => ...) packt diesen Inhalt in deinen Platzhalter hinein.
  • Dadurch wird das Menü beim Laden der Seite vollautomatisch eingefügt!

04. So sieht der Code in der `nav.html` aus

Ein typisches Agentur-Menü besteht aus einem Logo, normalen Links und einem Dropdown:

  • <a href="index.html" class="logo">DeinName.</a>
  • Einer Liste von Links (<ul class="nav-links">)
  • Einem optionalen Dropdown-Bereich für deine Unterseiten und Materialien.

Hilfe-Bereich: Kopierfertiger Code für die `nav.html`

So sieht eine komplette nav.html aus

Wenn du dir unsicher bist, wie der Code für die ausgelagerte Menü-Datei aussehen muss, kannst du diesen Baustein als Vorlage verwenden:

<nav>
    <a href="index.html" class="logo">CodeLaunch.</a>
    <ul class="nav-links">
        <li><a href="index.html">Anleitung</a></li>
        
        <!-- Dropdown für Materialien -->
        <li class="dropdown">
            <a href="#" class="drop-btn">Materialien ▾</a>
            <div class="mega-dropdown">
                <div class="dropdown-content">
                    <a href="aufgaben.html">
                        <strong>Projekt-Aufgabe 🎯</strong>
                        <span>Die Challenge & Checkliste</span>
                    </a>
                    <a href="htmlbasics.html">
                        <strong>HTML Basics</strong>
                        <span>Überschriften, Texte, Links & Bilder</span>
                    </a>
                </div>
            </div>
        </li>

        <li><a href="kontakt.html">Kontakt</a></li>
        <li><a href="https://github.com" target="_blank" class="btn-primary">Zu GitHub ↗</a></li>
    </ul>
</nav>
