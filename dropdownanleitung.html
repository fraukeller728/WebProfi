Das Dropdown-Menü 🔽

Erfahre, wie man ein modernes Aufklappmenü baut, das sich beim Darüberfahren (Mouseover) mit der Maus sanft öffnet.

Wie funktioniert der Aufklapp-Effekt?

01. Die Verschachtelung in HTML (`nav.html`)

Das Untermenü liegt als eigener Container innerhalb eines Listenpunktes (<li class="dropdown">):

  • Der Hauptpunkt bekommt die Klasse .dropdown.
  • Darin befindet sich ein Container <div class="mega-dropdown"> mit deinen Unterlinks.
  • Durch diese Verschachtelung "weiß" der Browser, welche Links zusammengehören.

02. Standardmäßig unsichtbar (`style.css`)

Im normalen Zustand ist das Dropdown-Fenster nicht zu sehen:

  • display: none; – Blendet das Menü komplett aus.
  • position: absolute; – Platzierte das Untermenü direkt unter dem Hauptknopf, ohne den restlichen Inhalt zu verschieben.
  • position: relative; (am Hauptpunkt) – Das Dropdown orientiert sich exakt an seinem Eltern-Button.

03. Die Magie von `:hover`

Sobald die Maus über den Hauptpunkt fährt, schaltet das CSS das Menü sichtbar:

  • .dropdown:hover .mega-dropdown { display: block; }
  • Bedeutung: "Wenn die Maus über .dropdown schwebt (hover), setze den Zustand von .mega-dropdown auf sichtbar!"

04. Der Agentur-Look für das Menü

Für den schicken, modernen Look sorgen ein paar zusätzliche CSS-Tricks:

  • box-shadow: 0 10px 30px rgba(0, 0, 0, 0.1); – Erzeugt einen weichen Schatten unter der Box.
  • border-radius: 8px; – Sorgt für sanft abgerundete Ecken.
  • transition: background-color 0.2s; – Lässt die Unterpunkte beim Drüberfahren sanft die Farbe wechseln.
