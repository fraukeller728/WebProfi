Spielregeln fürs Projekt 📋

Damit alles fair bleibt, jede_r optimal lernen kann und das Projekt ein voller Erfolg wird, gelten diese vier klaren Regeln.

Fairplay & Arbeitsweise

01. Eigenes Projekt

Jede_r bearbeitet seine GitHub-Seite komplett alleine. Du bist der Chef / die Chefin deines eigenen Repositories und trägst die Verantwortung für deine Website.

02. KI-Nutzung ist erlaubt

Die Arbeit mit Künstlicher Intelligenz (z. B. als Assistenz zum Erklären von Code oder Finden von Ideen) ist ausdrücklich erlaubt. Wichtig dabei:

  • Alle generierten Texte und Codes müssen von dir kritisch verifiziert (überprüft) werden.
  • Du musst verstehen, was dein Code tut!

03. Kein Abschreiben

Abschreiben oder das direkte Teilen von Code mit anderen ist nicht erlaubt.

  • Kopiere keine fremden Repositories oder fertigen Quelltexte von Mitschüler_innen.
  • Hilfestellung und Tipps geben ist super – aber jede_r schreibt den Code selbst.

04. Finde deinen eigenen Stil

Sei kreativ und gestalte eine Website, die zu dir passt:

  • Recherchiere vorher im Internet nach Webseiten, Agenturen oder Designs, die dir richtig gut gefallen.
  • Verwende diese als Inspiration und Referenz für dein eigenes Design.
