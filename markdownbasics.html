Markdown & YAML Basics ✍️

Lerne die Grundlagen der Syntax kennen: Wie du Metadaten in YAML festlegst und Texte in Markdown schnell und einfach formatierst.

1. Was ist YAML Front Matter?

Metadaten am Anfang jeder Datei

Jede Markdown-Datei für GitHub Pages beginnt ganz oben mit einem Kopfbereich in YAML. Dieser wird zwischen zwei Zeilen mit --- eingeschlossen:

---
layout: default
title: "Willkommen auf meiner Website"
description: "Eine kurze Beschreibung für Suchmaschinen"
---

2. Die wichtigsten Markdown-Befehle

Überschriften

Verwende Raute-Zeichen (#) am Zeilenanfang:

  • # Hauptüberschrift (H1)
  • ## Unterüberschrift (H2)
  • ### Kleine Überschrift (H3)

Text-Formatierung

Hebe wichtige Wörter im Text hervor:

  • **Fetter Text** → Fetter Text
  • *Kursiver Text* → Kursiver Text
  • ~~Durchgestrichen~~ → Durchgestrichen

Links & Bilder

Einfaches Einbinden von Verweisen und Medien:

  • [Link-Text](https://github.com) → Web-Link
  • [Unterseite](ueber-mich.html) → Link zu eigener Seite
  • ![Bildbeschreibung](mein-bild.jpg) → Bild anzeigen

Listen & Aufzählungen

Strukturiere deine Stichpunkte übersichtlich:

  • - Erster Punkt (Spiegelstrich)
  • - Zweiter Punkt
  • 1. Nummerierter Punkt
  • 2. Nummerierter Punkt

Hilfe-Bereich: Komplettes Markdown-Beispiel

Kopierfertige Vorlage für eine `index.md`

So kann deine komplette Markdown-Datei aussehen:

---
layout: default
title: "Startseite"
---

# Hallo Welt! 🚀

Willkommen auf meiner neuen Website. Ich erstelle diese Seite im Informatikunterricht.

## Meine Themen
- Erfahren, wie Markdown funktioniert
- GitHub Pages kennenlernen
- Eigene Inhalte im Web veröffentlichen
