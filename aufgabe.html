Deine Projekt-Aufgabe 🎯

Jetzt bist du am Zug! Wende dein Wissen an und erstelle deine eigene, funktionierende Website auf GitHub Pages.

Die Challenge: Was baust du?

01. Das Thema wählen

Du hast freie Wahl! Erstelle eine Mini-Website zu einem Thema deiner Wahl:

  • Option A: Deine persönliche digitale Visitenkarte (Über mich, Hobbys, Lieblingsmusik).
  • Option B: Eine Fan-Page zu deinem Lieblingsspiel, Sportverein oder einer Band.
  • Option C: Ein Infoportal zu einem Schulfach oder Lieblingsthema (z. B. Weltall, Tiere, Geschichte).

02. Pflichtelemente (Checkliste)

Deine Website muss folgende technische Elemente enthalten:

  • Eine Startseite index.html.
  • Mindestens drei Seiten (z. B. Startseite index.html und zwei Unterseiten im Dropdownmenü).
  • Sauber strukturierte, einheitliche Überschriften (<h1>, <h2>) und Textabsätze (<p>).
  • Mindestens eine funktionierende Liste oder Aufzählung.
  • Ein eingebundener Link (z. B. zu einer externen Info-Quelle).
  • Das Design muss über die zentrale style.css (Farben, Abstände, Schriftart) angepasst sein.
  • Es muss eine Navigationsleiste nav.html geben.

03. Meilensteine für den Unterricht

Arbeite Schritt für Schritt auf das Endergebnis hin:

  • Meilenstein 1: GitHub-Konto einrichten, Repository anlegen und die Seite live schalten.
  • Meilenstein 2: Inhalte in der index.html schreiben und das Design mit CSS verfeinern.
  • Meilenstein 3: mindestens zwei weitere Seiten schreiben und über das Menü erreichbar machen.
  • Meilenstein 4: Zwei Unterseiten anlegen und über das Menü erreichbar machen.
  • Meilenstein 5: Am Ende den Live-Link abgeben und stolz herzeigen! 🚀

04. Worauf kommt es an?

Am Ende zählt nicht Perfektion, sondern dass:

  • Deine Website fehlerfrei im Internet unter deiner GitHub-URL erreichbar ist.
  • Der Code sauber und lesbar formatiert ist.
  • Du kreativ warst und Spaß am Ausprobieren hattest!
