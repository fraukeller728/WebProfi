Webseiten mit KI erstellen 🚀

Anleitung & Prompt-Guide, um den typischen „KI-Einheitsbrei“ zu umgehen und moderne Websites im Editorial- / Magazin-Stil zu bauen.

So funktioniert's

Der Workflow für deine Schüler_innen

KIs wie Gemini oder Copilot neigen standardmäßig zu langweiligen Layouts (Lila Verläufe, Bento-Boxen mit Schatten, Einheits-Schriften). Mit diesen vier aufeinanderfolgenden Prompts zwingst du die KI dazu, professionellen, schicken Code im Magazin-Stil zu schreiben, den du direkt in GitHub hochladen kannst.

  • Schritt 1: Design-System und CSS-Fundament festlegen (Schriften, Farben, Linien).
  • Schritt 2: Asymmetrisches Layout und Rhythmus definieren.
  • Schritt 3: Mikro-Details (Seitenränder, Labels, Print-Ästhetik) ergänzen.
  • Schritt 4: Code sauber für GitHub aufteilen (index.html & style.css).

Die 4 Bausteine (Prompts)

Schritt 1 von 4

Das Editorial-Design-System & CSS-Fundament

Diesen Prompt schickst du als Erstes an die KI, um den Grundstil zu definieren:

Du bist ein erfahrener High-End Frontend-Entwickler und UI-Designer. Ich möchte eine Website im stilvollen "Editorial Magazin-Look" erstellen. 

Generiere ein sauberes, modernes CSS/HTML-Fundament mit folgenden Eigenschaften:

1. TYPOGRAFIE:
   - Binde Google Fonts ein: Eine markante, edle Serifenschrift für Überschriften (z. B. 'Playfair Display' oder 'Instrument Serif') kombiniert mit einer extrem sauberen, modernen Sans-Serif für Fließtext (z. B. 'Plus Jakarta Sans').
   - Setze auf extreme Typografie-Kontraste: Große Display-Headlines, kleine feine Labels in UPPERCASE mit vergrößertem Zeichenabstand.
   - KEINE Standard-Schriften wie Inter, Arial oder Roboto.

2. FARBPALETTE & ATMOSPHÄRE:
   - Basis: Ein sehr helles, kühles Grau/Off-White (#F7F7F8) oder reinweißes Papier-Feeling mit tiefschwarzer/dunkelgrauer Typographie (#111111).
   - Akzente: Verwendet wird nur ein einziger, hochpräziser Akzentton (z. B. ein tiefes Mitternachtsblau #0F172A).
   - KEIN Lila-Verlauf, kein Creme/Terrakotta, kein Neon-Grün.

3. UI-ELEMENTE & STRUCTURING:
   - Trennlinien: Verwende feine, saubere 1px Solid-Borders, um Sektionen wie in einer Zeitung klar abzugrenzen.
   - Kanten & Schatten: Verwendungs-Verbot für weiche Schlagschatten (box-shadow: none). Ecken sind strikt scharfkantig (border-radius: 0px) oder minimal angepasst.

Erstelle mir dafür zunächst das vollständige CSS-Setup.
Schritt 2 von 4

Asymmetrisches Magazin-Layout & Grid-Rhythmus

Nutze diesen Prompt im selben Chat, um den Seitenaufbau strukturieren zu lassen:

Baue nun das HTML-Layout für die Hauptseite auf. Nutze HTML5-Semantik (<header>, <main>, <section>, <article>, <footer>).

Beachte folgende Editorial-Prinzipien:
1. LAYOUT-STRUKTUR:
   - Kein zentriertes Einheits-Layout. Nutze ein modernes CSS Grid mit asymmetrischen Spalten (z. B. 30/70 oder 40/60).
   - Wechsel den Rhythmus der Sektionen: Eine dominante Hero-Headline, ein 3-Spalten-Raster mit vertikalen Trennlinien und ein großes Zitat (Blockquote) mit riesiger Serif-Typografie.
   - Nutze viel negativen Raum (Weißraum), damit das Design luftig und wie ein gedrucktes Hochglanz-Magazin wirkt.

2. KEINE KI-STEREOTYPE:
   - Keine abgehackten Bento-Boxen mit Schatten.
   - Keine abgerundeten Standard-Buttons. Buttons sind minimalistisch mit feinem Border.

Gib mir den vollständigen HTML-Code für dieses Sektions-Raster.
Schritt 3 von 4

Mikro-Details & Magazin-Optik

Hiermit verleihst du der Seite den echten Feinschliff an den Rändern:

Verfeinere das Layout nun mit typischen High-End Magazin-Elementen:

1. Vertikale Text-Elemente / Margin-Notes:
   - Erstelle CSS-Klassen für dezent gedrehte oder vertikal ausgerichtete Meta-Texte am Seitenrand (z. B. "ISSUE N° 01", "ARTICLE / ARCHIVE").

2. Print-Details:
   - Füge Platzhalter für kleine Index-Nummern (z. B. "01.", "02.") über den Überschriften und Datumsangaben ein.
   - Bild-Container: Bilder haben keine abgerundeten Ecken, sondern feine Bildunterschriften in kleiner Sans-Serif mit feiner Oberlinie.

3. Hover-Effekte:
   - Halte Animationen extrem dezent und elegant (nur sanfte Opacity-Änderungen oder Border-Transitions).

Füge diese CSS-Detailklassen und HTML-Beispiele hinzu.
Schritt 4 von 4

Export-Optimierung für GitHub

Am Ende trennst du den Code sauber auf, um ihn direkt in GitHub hochzuladen:

Ich möchte diesen Code auf GitHub veröffentlichen. Bitte strukturiere das finale Ergebnis perfekt für mein Repository:

1. Trenne den Code sauber in zwei Dateien:
   - `index.html`: Vollständiger, valider HTML5-Code inklusive semantischer Tags und verknüpfter CSS-Datei.
   - `styles.css`: Der komplette, strukturierte CSS-Code mit klar dokumentierten Abschnitten.

2. Stelle sicher, dass der Code vollkommen responsive ist (Mobile-First Breakpoints für Smartphones und Tablets).

Gib die Dateien jeweils in eigenen, sauber benannten Code-Blöcken aus.
