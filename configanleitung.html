Die Konfiguration (`_config.yml`) ⚙️

Die Datei _config.yml ist die Steuerung deiner Website auf GitHub. Hier wählst du dein Design-Theme aus und legst Titel und Untertitel fest.

Wie funktioniert die `_config.yml`?

01. Datei im Hauptverzeichnis anlegen

Erstelle die Konfigurationsdatei direkt im Wurzelverzeichnis (root) deines Repositories.

  • Klicke auf Add file → Create new file.
  • Nenne die Datei exakt _config.yml (Achte unbedingt auf den Unterstrich _ am Anfang!).

02. Syntax beachten (YAML)

YAML ist sehr übersichtlich, aber streng bei der Schreibweise:

  • Schlüssel und Wert werden durch einen Doppelpunkt getrennt (z. B. title: Mein Titel).
  • Nach dem Doppelpunkt kommt immer ein Leerzeichen.
  • Nutze keine Tabulatoren, sondern normale Leerzeichen für Einrückungen.

03. Verfügbare Themes

GitHub Pages bietet kostenlose vorgefertigte Layouts (Themes), die du einfach über die Config aktivieren kannst:

  • jekyll-theme-cayman (Modern & Bunt)
  • jekyll-theme-minimal (Schlicht & Minimalistisch)
  • jekyll-theme-architect (Klar & Strukturiert)
  • jekyll-theme-tactile (Kompakt & Übersichtlich)
  • jekyll-theme-slate (Dunkles Design / Dark Mode)

Hilfe-Bereich: Kopierfertiger Code für die `_config.yml`

Beispiel-Code zum Kopieren

Kopiere diesen Code in deine _config.yml-Datei und passe den Titel, die Beschreibung und deinen Namen an:

# --- HOUPTEINSTELLUNGEN DER WEBSITE ---
title: "Mein Schulprojekt"
description: "Meine erste eigene Website mit GitHub Pages und Markdown"
author: "Dein Name"

# --- DESIGN-THEME AUSWÄHLEN ---
# Mögliche Optionen: jekyll-theme-cayman, jekyll-theme-minimal, jekyll-theme-architect, jekyll-theme-slate
theme: jekyll-theme-cayman

# --- OPTIONALE PLUGINS ---
plugins:
  - jekyll-feed
  - jekyll-seo-tag
