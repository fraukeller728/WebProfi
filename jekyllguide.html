Webseite mit Markdown & YAML 📝

GitHub Pages kann aus einfachen Markdown-Dateien automatisch eine fertige Website generieren. Du brauchst dafür kaum HTML – sondern nur Markdown und YAML!

In 4 Schritten zur Markdown-Website

01. Konfiguration anlegen (`_config.yml`)

GitHub nutzt den Generator Jekyll. Mit einer Konfigurationsdatei wählst du ein vorgefertigtes Design (Theme) aus.

  • Erstelle im Repository eine neue Datei namens _config.yml.
  • Schreibe deinen Titel und wähle ein GitHub-Theme aus (z. B. theme: jekyll-theme-cayman oder jekyll-theme-minimal).
  • Speichere mit Commit changes....

02. Startseite in Markdown (`index.md`)

Erstelle deine Startseite als Markdown-Datei statt als HTML-Datei.

  • Erstelle eine neue Datei namens index.md (oder erstelle eine README.md).
  • Verwende oben den YAML Front Matter Bereich zwischen zwei --- Linien.
  • Schreibe deinen eigentlichen Text darunter in einfacher Markdown-Schreibweise.

03. Weitere Seiten anlegen

Unterseiten werden genauso wie die Startseite erstellt.

  • Erstelle z. B. eine Datei ueber-mich.md oder projekte.md.
  • Füge oben den YAML-Kopf mit dem Titel der Seite ein.
  • Verlinke die Seiten untereinander einfach per Markdown: [Über mich](ueber-mich.html). (Hinweis: GitHub baut aus .md automatisch .html-Dateien!).

04. GitHub Pages aktivieren

Aktiviere das automatische Erstellen deiner Seite in GitHub.

  • Gehe im Repository auf Settings → Pages.
  • Stelle den Branch auf main und wähle den Ordner / (root).
  • Nach ca. 1–2 Minuten verwandelt GitHub deine Markdown-Dateien in eine schicke Website!
