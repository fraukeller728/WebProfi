Neue Seiten anlegen & verlinken 📄

Eine Website besteht meist aus mehreren Seiten. Hier lernst du, wie du neue HTML-Dateien erstellst und sie in dein Navigationsmenü einbindest.

In 3 Schritten zu deiner neuen Unterseite

01. Neue HTML-Datei auf GitHub erstellen

Erstelle für jede neue Unterseite eine eigene Datei in deinem Repository.

  • Klicke in deinem GitHub-Repository auf Add file → Create new file.
  • Vergib einen kurzen, kleingeschriebenen Namen ohne Leerzeichen (z. B. ueber-mich.html oder projekte.html).
  • Füge das grundlegende HTML-Gerüst ein und klicke unten auf Commit changes....

02. Vorlage für deine neue Seite

Kopiere diesen Code als Startpunkt für jede deiner neuen Seiten:

  <!DOCTYPE html>   <html lang="de">   <head>   <meta charset="UTF-8">
  <title>Meine neue Seite</title>
  <link rel="stylesheet" href="style.css">    </head>   <body>
  <header id="header-placeholder"></header>
  <main>... Dein Inhalt ...</main>
  <script>fetch('nav.html').then(r => r.text()).then(d => document.getElementById('header-placeholder').innerHTML = d);</script>
</body></html>

03. Ins Navigationsmenü (`nav.html`) eintragen

Damit Besucher deine neue Seite auch finden, musst du sie in der nav.html verlinken.

  • Öffne deine Datei nav.html auf GitHub und klicke auf das Stift-Symbol (Bearbeiten).
  • Füge einen neuen Listenpunkt hinzu:
    <li><a href="ueber-mich.html">Über mich</a></li>
  • Oder füge die Seite im Dropdown-Menü ein:
    <a href="ueber-mich.html"><strong>Über mich</strong><span>Mehr über mein Projekt</span></a>
  • Speichere mit Commit changes.... Die Änderung ist sofort auf allen Seiten sichtbar!

💡 Wichtige Tipps für Dateinamen:

  • Schreibe Dateinamen immer klein (z. B. kontakt.html statt Kontakt.html).
  • Vermeide Leerzeichen und Umlaute (nutze ue statt ü, - statt Leerzeichen).
  • Ende immer auf .html!
